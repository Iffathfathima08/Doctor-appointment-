# Doctor Appointment System

A simple web-based Doctor Appointment system that allows users to book appointments with doctors. The system uses a form to gather user details, and upon submission, a success page is displayed to confirm the appointment booking. This project is built using HTML, CSS, and JavaScript.

## Features

- **User-friendly Appointment Form**: A straightforward form for users to fill in their personal information and appointment details.
- **Success Page**: After form submission, the user is redirected to a confirmation page (`success.html`), confirming the successful submission of their appointment request.
  
## Tech Stack

- **Frontend**: HTML, CSS, JavaScript

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Kalaigar-Ayesha/Doctor-appointment.git
   ```

2. Open `index.html` in your browser to start using the application.

## Usage

- Fill in the form and click **Submit**.
- After submission, you'll be redirected to `success.html` confirming your appointment.
